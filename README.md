# 統計量チャレンジ

整数のドットを動かし、目標の統計量をそろえる教育用Webアプリです。外部ライブラリ・外部フォント・ビルド工程はありません。ページ読み込み時にGoogle Apps Scriptへアクセス記録用のGETを1回送信します。アプリ内操作では再送信せず、通信失敗はゲームに影響しません。

## 起動・公開

このディレクトリを静的Webサーバーで配信してください。例：

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。ES Modulesを使うため、HTMLの直接ダブルクリックではなくHTTPで開いてください。

GitHub Pagesでは Settings → Pages → Deploy from a branch から、公開するブランチの `/ (root)` を選択します。すべて相対パスのため、リポジトリ名のサブパスでも動作します。

## 使い方

- 代表値・5数要約・散らばり・平均と分散の4モード。
- 点をマウス／タッチでドラッグするか、点を選んで「−」「＋」で移動します。
- キーボードではTabで点を選び、左右矢印で移動。Home / Endは範囲の両端に移動します。
- 設定の変更は「新しい問題」で反映。モード切替でも新しい問題を生成します。
- リセットは同じ問題の初期配置に戻ります。目標は変化しません。
- クリア時は一致した統計量をまとめたCLEAR画面と約2秒の紙吹雪を表示します。「新しい問題」で次へ、「もう一度」で同じ初期配置に戻ります。閉じるボタンやEscapeでデータに戻れます。端末で動きを減らす設定がある場合、演出を省略します。
- 移動した点は青色、選択中の点は輪付きの緑色です。移動回数はドラッグ完了時または1回のボタン・キー操作ごとに加算します。

通常のデータ数は2〜100個の任意の整数、平均・分散モードは10個または20個です。値の範囲は0〜10・0〜20・0〜50の3択で、初期値は0〜20です。どの範囲も1刻みの整数位置に点を置けます。

プロットと箱ひげ図は利用可能な横幅に収まります。範囲・データ数・最大積み上げ数から、点のサイズ、縦の間隔、数字ラベルの表示間隔を自動調整します。0〜50は範囲・個数・積み上げ密度に応じて横幅を約13〜20％縮め、中央に配置します。低密度では従来の点の大きさをなるべく保ちます。100個が同じ値でもプロットの高さは380px以下です。密集時も32pxの判定領域と最近傍の点の選択を使い、点を直接クリック／タップして選び、「− / ＋」でも移動できます。移動した点は必ず移動先の列の一番上に追加され、他の点の順序は維持されます。リセットで積み上げ順も初期状態に戻ります。

## 計算と問題生成

先に正解の整数データを生成し、そこから目標を計算します。代表値モードでは最頻値が一意の正解を生成します。初期配置は240候補を比較し、未達成項目の多さ、正解とのデータの違いと距離、点の分布を基準に選びます。狭い範囲・少数データでは難易度に限界がありますが、初期状態で全項目が一致する問題は除外します。正解データは画面に表示しません。

四分位数：データを小さい順に並べ、中央値を第2四分位数とします。データを前半と後半に分け、それぞれの中央値を第1四分位数、第3四分位数とします。データの個数が奇数の場合、全体の中央値は前半・後半には含めません。2個の場合はQ1が最小値、Q3が最大値です。

分散は母分散 `Σ(xᵢ − 平均)² / n`。計算には同値な `(n × Σxᵢ² − (Σxᵢ)²) / n²` を使い、BigIntの整数分子・分母で正確に比較し、筆算によって小数に変換します。平均・分散モードの表示は丸めを行いません。通常モードは小数第3位まで表示し、さらに続きがある場合は `5.923…` のように省略を明示します。四捨五入はしません。3桁以内で終わる有限小数はそのまま表示し、不要な末尾の0は付けません。表示が同じでも、正確な値が異なれば一致にはなりません。通常の分散・平均計算に浮動小数点演算は使いません。

標準偏差だけは分散の平方根を近似計算し、小数第4位まで「約」を付けて表示します。クリア判定には使いません。箱ひげ図のひげは最小値・最大値で、外れ値の除外はしません。

## 検証

Node.js 18以降で、追加インストールなしに計算と問題生成を検証できます。

```sh
node --test tests/*.test.mjs
```
